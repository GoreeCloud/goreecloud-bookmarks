# GoreeCloud Bookmarks — Branding

## Product name

**GoreeCloud Bookmarks**

Use the full product name in formal documentation, repository metadata, release records, public pages, and first-use references. “Bookmarks” may be used as a short in-product label where the GoreeCloud context is already clear.

## Product concept

> **Save anything. Preserve what matters. Find it again instantly.**

Supporting workflow principle:

> **Capture instantly → enrich automatically → organize when useful → preserve when important → rediscover when relevant.**

## Visual direction

GoreeCloud Bookmarks should use the current approved Stable **Glaze UI** consumer contract at the time a user-facing implementation is built and qualified. The current Official Stable Glaze UI consumer target is `1.6.0`; documentation of that target is not Bookmarks-specific acceptance evidence.

Intended product-specific visual emphasis includes:

- Saved-content previews as the primary visual object.
- Layered surfaces and contextual depth consistent with Glaze UI.
- Collection identity and functional state indicators.
- Clear distinction for offline, archive, privacy, sharing, reminder, and health states.
- Light and dark appearance modes where supported by the current Glaze UI contract.
- Non-color indicators for important state and accessibility.

## Iconography and marks

No repository-local logo, icon, trademark treatment, or color palette should be treated as canonical until an approved GoreeCloud branding asset or product-specific brand record establishes it.

Do not invent a Bookmarks logo by modifying unrelated GoreeCloud artwork without the required design/branding authority.

## Naming guardrails

- Do not imply that planned features are available by labeling screenshots, mockups, or conceptual UI as released functionality.
- Do not describe Bookmarks as “Stable,” “production-ready,” or “fully integrated” without authoritative evidence.
- Related components such as `GoreeCloud/goreecloud-bookmark-browser-extension` should retain their own repository identity while clearly describing their relationship to GoreeCloud Bookmarks.

## Accessibility

Brand expression must not override accessibility. Contrast, focus visibility, scalable typography, reduced-motion behavior, readable state labels, and non-color status communication remain functional requirements.
