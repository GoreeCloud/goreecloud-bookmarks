# GoreeCloud Bookmarks

GoreeCloud Bookmarks is the planned GoreeCloud bookmarking, web-archiving, read-later, annotation, and personal web-memory platform.

> **Current repository state:** Documentation foundation only. No GoreeCloud Bookmarks application or service implementation is currently verified in this repository.

## Product direction

The intended product combines:

- One-click bookmark capture.
- Deep GoreeCloud Browser integration.
- Collections, nested collections, tags, Inbox, Read Later, favorites, and pins.
- Full-content and archived-content search.
- Optional meaning-based retrieval.
- Readable extraction, web archiving, archive version history, and link-health monitoring.
- Highlights, annotations, and lightweight research notes.
- Offline-first desktop and mobile behavior.
- Conflict-tolerant synchronization and sync history.
- Import, export, backup, and long-term portability.
- Private-by-default sharing and optional collaboration.
- Automation rules, Smart Collections, reminders, rediscovery, and optional feed following.
- Explicit privacy levels, including a planned higher-privacy Private Vault mode.

The guiding product concept is:

> **Save anything. Preserve what matters. Find it again instantly.**

The preferred workflow is:

> **Capture instantly → enrich automatically → organize when useful → preserve when important → rediscover when relevant.**
