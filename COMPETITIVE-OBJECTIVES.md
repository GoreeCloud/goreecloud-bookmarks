# GoreeCloud Bookmarks — Competitive Objectives

## Status

These are design objectives for the planned product, not claims that GoreeCloud Bookmarks currently matches or exceeds any named alternative.

## Objectives

GoreeCloud Bookmarks should compete on the combined strength of:

- **Integrated capture:** native GoreeCloud Browser workflows rather than a disconnected bookmark utility.
- **Durable preservation:** readable and complete archival options, version history, and source-health awareness.
- **Search depth:** one search surface spanning metadata, extracted content, archives, notes, and highlights.
- **Offline-first behavior:** useful local libraries on installed clients with resilient synchronization.
- **Privacy:** private-by-default storage, explicit sharing, optional local/high-privacy processing, and minimum external requests.
- **Portability:** strong import, export, backup, and recovery rather than ecosystem lock-in.
- **Rediscovery:** deliberate mechanisms for surfacing forgotten saved information.
- **Automation:** simple default capture with advanced rules and Smart Collections for power users.
- **Cross-platform consistency:** one underlying library across Browser, web, desktop, and mobile interfaces.
- **Safe archival:** isolated rendering of captured pages instead of treating preserved web content as trusted active applications.
- **Research utility:** annotations, highlights, notes, versions, relationships, and public/private collection workflows without turning Bookmarks into a full general-purpose note suite.

## Guardrails

Competitive development must not weaken:

- Privacy or security requirements.
- Data ownership and exportability.
- Accessibility.
- Offline capability.
- Truthful capability reporting.
- GoreeCloud application/domain authority boundaries.
- Current Integral Platform System and Platform Contract requirements.

## Success criterion

The intended differentiator is not any single feature. It is the combination of **effortless capture, dependable preservation, flexible organization, explicit privacy, broad portability, and powerful retrieval/rediscovery** in one GoreeCloud-owned system.
